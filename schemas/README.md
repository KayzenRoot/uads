# schemas

JSON Schema documents for Architecture Freeze v0.2 data types, Prompt 003 execution schemas at 0.3.0 (`execution-run`, `execution-packet`, `evidence-record`, `review-record`), Prompt 004 intelligence schemas at 0.4.0 (`index-state`, `dependency-graph`, `test-map`, `interface-map`, `impact-report`, `context-pack`), Prompt 005 failure schemas at 0.5.0 (`failure-record`, `diagnosis-report`, `failure-memory`), Prompt 006 cache/cost schemas at 0.6.0 (`evidence-cache-record`, `cache-decision`, `cost-ledger`, `qpt-snapshot`), and Prompt 008 model-routing schemas at 0.8.0 (`model-profile`, `model-profile-registry`, `runtime-capability-snapshot`, `model-execution-plan`). Evidence records may optionally carry `source=cache-reuse` provenance. Context Packs may optionally carry layer digests. Model schemas are provider-neutral and contain no credential or provider invocation contract. Index state records completeness (`complete`, `truncated`, `truncationReason`); unresolved graph entries bind `sourceDigest`. Diagnosis ranking is heuristic and is not a verified root-cause claim. QPT is a documented byte-heuristic ratio, not financial cost.

UADS by NexLabs. See `docs/` for Architecture Freeze v0.2.

The `github-direct-review-evidence.schema.json` contract is strict and versioned at 0.8.0. It binds exact-SHA GitHub CI evidence, bounded test/evaluation/audit summaries, security workflow status, release identity, artifact provenance, and explicit PASS/FAIL/INCOMPLETE verdicts. Unavailable counts remain `null` with an uppercase `COUNT_PARSE_UNAVAILABLE:*` reason code.
