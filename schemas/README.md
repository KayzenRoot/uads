# schemas

JSON Schema documents for Architecture Freeze v0.2 data types, Prompt 003 execution schemas at 0.3.0 (`execution-run`, `execution-packet`, `evidence-record`, `review-record`), Prompt 004 intelligence schemas at 0.4.0 (`index-state`, `dependency-graph`, `test-map`, `interface-map`, `impact-report`, `context-pack`), and Prompt 005 failure schemas at 0.5.0 (`failure-record`, `diagnosis-report`, `failure-memory`). Index state records completeness (`complete`, `truncated`, `truncationReason`); unresolved graph entries bind `sourceDigest`. Diagnosis ranking is heuristic and is not a verified root-cause claim.

UADS by NexLabs. See `docs/` for Architecture Freeze v0.2.
